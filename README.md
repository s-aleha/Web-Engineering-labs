## Lab 02: Semantic HTML and Accessibility Foundations

**Topics covered:**

- Semantic HTML landmarks (`header`, `nav`, `main`, `footer`)
- Correct heading hierarchy (h1 → h2 → h2)
- Accessible data tables with `<caption>`, `<thead>`, `scope`, and `<time>`
- Decorative vs informative graphics (`aria-hidden`, `role="img"`, `<title>`)
- Accessible forms with `<label>`, `<fieldset>`, `<legend>`
- Keyboard operability and visible focus indicators
- ARIA best practices (only where semantic HTML is not enough)
- Automated testing with **axe DevTools** and **Lighthouse**

**Key features implemented:**

### 1. Semantic Structure

- Skip to main content link (first focusable element)
- Landmark elements: `header`, `nav`, `main`, `footer`
- Exactly one `<main id="main-content">`
- Sequential heading hierarchy

### 2. Accessible Table

- `<caption>Weekly office hours</caption>`
- `<thead>` with `scope="col"` headers
- `<tbody>` with data rows
- `<time datetime="...">` for machine-readable times

### 3. Graphics Accessibility

| Graphic            | Treatment                                       |
| ------------------ | ----------------------------------------------- |
| Decorative divider | `aria-hidden="true"` (silent to screen readers) |
| Location pin icon  | `role="img"` + `<title>` (accessible name)      |

### 4. Accessible Form

- Every control has a `<label for>` + `id` pair
- Radio group wrapped in `<fieldset>` + `<legend>`
- Hint text linked with `aria-describedby`
- Real `<button type="submit">`

### 5. Keyboard Operability

- 8 tab stops from skip link to submit button
- Visible focus: `outline: 3px solid #0b5fff`
- Skip link revealed on first Tab press
- Radio group is a single tab stop (arrow keys navigate)

### 6. ARIA Usage

| Attribute                 | Where           | Why                      |
| ------------------------- | --------------- | ------------------------ |
| `aria-hidden`             | Decorative SVG  | Hide from AT             |
| `role="img"` + `<title>`  | Location pin    | Provide name             |
| `aria-describedby`        | Email input     | Link hint text           |
| `aria-current="location"` | Active nav link | Indicate current section |

**No redundant ARIA** — no `role="navigation"` on `<nav>`.

## Lab 04: Flexbox, Grid, Modules and the DOM

**Topics covered:**

- Flexbox for the header, navigation and location figure
- Grid for the Office Hours section (`2fr 1fr`) and the two-column feedback form
- One media query that switches both grids to a single column at 40rem
- ES modules (`main.js`, `utils.js`) with `import` and `export`
- DOM: `querySelector`, `querySelectorAll`, `classList.toggle`, `dataset`, `closest` and event delegation
- Event loop, microtasks, `async/await` and closures (see `NOTES.md`)

**Files:**

- `public/styles.css`: Flexbox and Grid layout, `.span-all`, selected-row style
- `public/main.js`: delegated click handler for booking a slot
- `public/utils.js`: `delay()` and `makeCounter()`
- `NOTES.md`: event-loop prediction and explanation

## Lab 05: Legacy Code, jQuery and TypeScript Foundations

**Topics covered:**

- Reading legacy jQuery and translating each call to native DOM (see `LEGACY-NOTES.md`)
- Porting the feedback validator to native JavaScript (no jQuery, `novalidate` on the form)
- Error styling with a `--color-error` token, `.error` and `input[aria-invalid="true"]`
- TypeScript with `strict`: annotations, interfaces (structural typing), union types with null narrowing, generics
- `tsc` compiles `src/*.ts` into `public/*.js`

**Files:**

- `src/main.ts`, `src/utils.ts`, `src/feedback.ts`: TypeScript source
- `public/*.js`: compiled output (generated by `npm run build`, do not edit by hand)
- `tsconfig.json`: `strict`, `rootDir: src`, `outDir: public`, `noEmitOnError`
- `LEGACY-NOTES.md`: six jQuery-to-native translations and three legacy smells
- `NOTES.md`: event-loop notes (Lab 04) and compiler errors (Lab 05)

**Commands:**

```bash
npm install
npm run typecheck   # check types only, prints nothing when clean
npm run build       # compile src/ to public/
npm start           # serve public/
```
